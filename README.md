# Grade Calculator in C

## Project Description
This is a simple Grade Calculator program developed using the C programming language. It accepts marks from the user, calculates the average score, and displays the corresponding letter grade.

## Features
- Accepts 1 to 5 grades from the user.
- Validates the number of grades.
- Calculates the average score.
- Displays the final letter grade.
- Uses conditional statements and loops.

## Grade Criteria

| Average | Letter Grade |
|---|---|
| 90 – 100 | A |
| 80 – 89 | B |
| 70 – 79 | C |
| 60 – 69 | D |
| Below 60 | F |

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Platform: Linux

## How to Compile

```bash
gcc grade_calculator.c -o grade
```

## How to Run

```bash
./grade
```
